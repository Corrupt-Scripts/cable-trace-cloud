Cable Trace marker

Print at 100% scale (no "fit to page"). Use A4 or any size, as long as the pattern square is exactly 150 mm.

▲
TOP (stick with this arrow pointing up)
  1. Stick it flat on a wall, door frame or consumer unit at the height set in the drawing editor.
  2. Measure the square. If it isn't 150 mm, enter the real size when you place the marker.
  3. Keep it clean and well lit. Don't fold, crop or cover the pattern.
